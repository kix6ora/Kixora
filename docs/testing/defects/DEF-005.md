## DEF-005 (Low)

**Description:** Four fulfillment tables (`fulfillment_locations`, `fulfillment_channels`, `inventory_sync_logs`, `fulfillment_batches`) had Row Level Security enabled but only a single admin policy (`admin_full_access_locations`) was defined for all of them. This resulted in missing policies for three tables, causing RLS errors.

**Root Cause:** Duplicate comment and copy‑paste error in `0020_fulfillment_audit.sql` created multiple `CREATE POLICY admin_full_access_locations` statements pointing at the same table, while the other tables never received their own admin‑only policy.

**Fix Implemented:**
- Removed the duplicate comment line.
- Ensured each table now has a distinct admin‑only policy (`admin_full_access_locations`, `admin_full_access_channels`, `admin_full_access_sync_logs`, `admin_full_access_batches`).
- Added migration `0027_fulfillment_policies.sql` that safely drops any existing policies and recreates them with the correct names.

**Status:** Fixed pending retest. No `DROP FUNCTION` or `CASCADE` statements were added.
